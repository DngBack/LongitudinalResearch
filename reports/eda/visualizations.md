# Label and image visualizations

- Scene-graph images: 243,310 (243,310 graph files)
- Label category: `anatomicalfinding`; only positive (`yes`) labels are counted.
- Label counts and co-occurrence count each label at most once per image.
- Correlation figure uses the phi coefficient for binary label presence.
- Sample images rendered from the supplied bbox PNG archive: 4
- The repository contains annotated PNG samples rather than the full original DICOM image collection.

Generated figures: `label_distribution.png`, `labels_per_image.png`, `label_correlation.png`, `image_counts.png`, and `sample_images_with_labels.png`.
